# Blender 电气数字孪生工作流与规范指南

## 1. 为什么工业数字孪生首选 Blender？
在专业电力系统数字孪生中，**Blender + Three.js + Vue 3** 是目前工业界最主流的生产级技术路线：
- **Blender 负责资产构建**：精密 CAD 工业模型轻量化减面、PBR 真实感物理材质烘焙（油漆、镀锌金属、陶瓷伞裙）、机械分合闸动作与设备爆炸拆解关键帧动画。
- **Three.js + Vue 3 负责数据与渲染交互**：通过标准 `.glb` 文件将模型加载至 WebGL 场景，将模型节点与电网 SCADA / 物联网测点（温度、电压、电流、开关状态）实时绑定。

## 2. 交互节点命名规范 (数据绑定协议)

在 Blender 大纲视图 (Outliner) 中为设备部件命名时，若遵循以下命名规则，前端系统在导入时将**自动识别并绑定对应的遥测数据、点击弹窗与状态灯**：

| Blender 对象名称 (Object Name) | 对应数字孪生业务实体 | 平台自动化功能 |
| :--- | :--- | :--- |
| `trans-1` 或包含 `Transformer` | 1# 主变压器 | 点击弹出油温/绕组温度测点抽屉，联动红外热成像着色器与爆炸拆解 |
| `trans-2` | 2# 主变压器 | 关联 2# 主变测点台账 |
| `gis-201` 或包含 `GIS_Breaker` | 220kV GIS 进线断路器 | 关联遥控分合闸、SF6 气体压力监测、电流粒子流通断联动 |
| `gis-101` | 110kV GIS 出线断路器 | 关联出线过载速断保护与故障跳闸模拟 |
| `Bushing_HV_*` | 高压侧绝缘套管 | 电流粒子流向接入锚点 |

## 3. Blender 导出 glTF 2.0 (.glb) 标准配置

在 Blender 中完成建模或装配后，点击顶部菜单 **File (文件) -> Export (导出) -> glTF 2.0 (.glb/.gltf)**：

1. **Format (格式)**：选择 **glTF Binary (.glb)**（单个独立二进制文件，内嵌所有网格、纹理与动画，传输最快）。
2. **Include (包含)**：
   - 勾选 `Selected Objects` (选中的物体，避免导出多余的摄像机和光源)。
   - 勾选 `Custom Properties` (自定义属性，方便携带设备电压等元数据)。
3. **Transform (变换)**：
   - `+Y Up`：**勾选**（保持与 WebGL / Three.js 坐标系一致）。
4. **Geometry (几何数据)**：
   - `Apply Modifiers` (应用修改器)：**勾选**（如镜像、倒角、阵列）。
   - `Compression` (Draco 压缩)：可选（若模型面数较高，勾选可将模型体积压缩 70%~90%）。
5. **Animation (动画)**：
   - 如果制作了变压器外壳展开爆炸动画或开关机构动作，勾选 `Animation` 与 `Shape Keys`。

## 4. 如何在本项目中直接使用 Blender 模型？

系统已内置了完整的 **glTF / glB 模型解析引擎**与文件上传接口：
1. **直接导入**：在变电站数字孪生界面顶部右上角，点击 **“导入 Blender (.glb)”** 按钮，选择您在 Blender 中导出的 `.glb` 文件。
2. **自动化渲染**：系统将自动计算模型包围盒居中放置、启用软阴影与 PBR 材质渲染，并自动循环播放模型内嵌的任何关键帧动画！
3. **工程内置放置（可选）**：如需随工程分发模型资产，可自行新建 `public/models/` 目录放入 `.glb`
   （Vite 会把 `public/` 原样拷贝进构建产物），再通过 `SubstationScene.loadGLTFModel()` 加载。
   当前工程默认走**程序化建模**、不依赖任何外部模型文件，以保证零延迟秒开与离线可用。
